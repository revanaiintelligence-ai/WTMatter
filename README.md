# WTM — WHAT'S THE MATTER?™

WTM (WHAT'S THE MATTER?™) es una capa de descubrimiento, clarificación y preparación de casos para BINAH.

Su función es transformar la información inicial proporcionada por un cliente y la conversación posterior en un caso estructurado, trazable y suficientemente claro para continuar hacia BINAH.

WTM no realiza el diagnóstico empresarial final.

---

## 1. Propósito

WTM busca responder, antes de iniciar el análisis de BINAH:

> ¿Qué está ocurriendo, qué necesita ser aclarado y qué información falta para poder analizar el caso?

WTM trabaja sobre:

- contexto;
- situación;
- objetivo;
- observaciones;
- evidencia;
- hipótesis;
- información desconocida;
- contradicciones;
- preguntas de clarificación;
- candidato de necesidad;
- trazabilidad.

El resultado no pretende resolver todavía el problema empresarial.

Su función es preparar correctamente el caso.
