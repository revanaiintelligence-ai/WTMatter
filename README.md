# WTM — WHAT'S THE MATTER?™

WTM (WHAT'S THE MATTER?™) es una capa de descubrimiento, clarificación y preparación de casos para BINAH.

Su función es convertir información inicial y conversación con el usuario en un caso estructurado, trazable y suficientemente claro para continuar hacia BINAH.

## Propósito

WTM responde principalmente:

> ¿Qué está ocurriendo, qué necesita ser aclarado y qué información falta antes de analizar el negocio?

WTM no realiza el diagnóstico empresarial final.

BINAH recibe el resultado estructurado de WTM y continúa con el análisis de necesidad, capacidad, brecha, realidad y alternativas.
